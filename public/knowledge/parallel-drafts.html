并行比稿规则

让多个 AI 各做一版来对比时，怎么避免互相覆盖

用户让 Claude Code / Codex / DeepSeek Harness / Cowork 中的多个工具各做一版同一个东西来对比时用。

背景

2026-09-15 起，三个工具的 zhuowang-workspace 入口都是软链，指向同一份实体 （我的知识库/卓望工作相关/卓望/）。本地即最新，不再靠 GitHub 互传。 代价：两个工具往同一个文件路径写，后写的会盖掉先写的，git 拦不住。

规则

  1. 比稿产物留在各自工作区（claude code new/卓望/、CODEX项目/拓维卓望/、deepseek harness/、Cowork 用 我的知识库/_草稿-cowork/）， 不放进本仓库。
  2. 文件名带工具后缀：xxx-claude.html / xxx-codex.html / xxx-dsh.html / xxx-cowork.html。
  3. 比稿阶段任何工具都不动 卓望.md、进度.md、流程/。开工检查照跑（只读），收工沉淀跳过， 收工时只说一句「比稿阶段，未写入仓库，等用户选定」。
  4. 用户选定某一版后，由被选中的那个工具跑 收工沉淀.md：
    • 定稿复制进本仓库对应项目目录，文件名去掉工具后缀、加「定稿」或版本号
    • 更新 进度.md
    • 有稳定结论再更新 卓望.md
    • 提交推送
  5. 落选版本不进仓库，留在各自工作区即可。

验收

  • 仓库里没有出现带 -claude/-codex/-dsh/-cowork 后缀的文件
  • 比稿期间 git -C <仓库> status --short 为空
  • 选定后只有一个工具做了沉淀，进度.md 只有一条对应更新
